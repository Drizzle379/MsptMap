# 按钮图标

地图左上角那两个按钮的图标。**这个目录不打包进模组**（只留档，方便以后换图标重做）。

| 文件 | 用途 |
|---|---|
| `draw_icons.py` | **画那两个图标的脚本** —— 跑一下就把 `assets/msptmap/textures/gui/{scan,close}.png` 重写一遍。改尺寸只改里面的 `WHITE_BOX` / `BAR_*` / `CROSS_ARM` |
| `README.md` | 这份说明（量出来的规格数字在下面） |
| `bar-chart-line.png`、`close-large-fill.png` | **上一版**用的 Remix Icon 原件，存档 |

## 规格是量出来的（照着 Xaero 自己的图标量的）

Xaero 的图标全在 `assets/xaeroworldmap/gui/gui.png`（256×256）里抠 16×16 用。把左下角那一列的四个（洞穴模式 `(229,64)`、维度切换 `(197,80)`、传送 `(213,80)`、跟随视角 `(229,80)`）抠出来量：

| 图标 | 白块范围 | 白块宽 | 含投影总墨迹 | 白/灰像素数 |
|---|---|---|---|---|
| 洞穴模式 | x 2~12, y 4~11 | 11 | 12×9 | 49 / 15 |
| 维度切换 | x 3~11, y 2~12 | 9 | 10×12 | 56 / 28 |
| 传送 | x 2~12, y 3~11 | 11 | 12×10 | 42 / 20 |
| 跟随视角 | x 5~11, y 2~13 | 7 | 8×13 | 30 / 15 |

三条结论：

1. **白块只有 7~11 px 宽**（连右下 1 px 投影一起算 8~12 px）——不是把整个 16×16 填满的。
2. **alpha 只有 0 和 255 两档**，一点半透明过渡都没有 —— 硬边像素画，所以在什么底色上都显得"实心"。
3. 不透明的颜色**只有两种**：白 `(255,255,255)` 和深灰 `(63,63,63)`。那个深灰是**右下方向的 1 px 投影**（每个白像素的右边/下面那一格），不是描边。

## 我们这两个怎么画的

`draw_icons.py` 直接按像素点画，不缩图、不抗锯齿：

- **`scan`（绘制地图）**：三根 3 px 宽的实心柱子，从矮到高（5 / 8 / 11 高），底边对齐；柱间留 1 px 空档，那一格会被投影填成深灰，正好当分隔线。
- **`close`（清空）**：3 px 笔画的 X，四条臂顶到白块的四个角。
- 两张都是 **11×11 白块 + 右下 1 px 投影 = 墨迹 12×12**，画在 16×16 贴图的正中（四周各留 2 px）。白块宽度和「洞穴模式」一样，落点也一样（贴图贴 `x=2`，白块从按钮的 `x=4` 起）。
- 颜色就那两种：白 + `(63,63,63)`，和 Xaero 一致（游戏里还会乘一层 `0xFFFCFCFC` 的染色，两边同样待遇）。

**画多大由代码里的 `textureW/H` 决定**（现在是 16），贴图本身必须是 16×16 —— 脚本里的 `TEX` 和 `GuiMapMixin` 里那两个 16 是一套，改一个要改另一个。

## 走过的弯路（别再踩）

第一版是拿 **Remix Icon** 的 24×24 细笔线图标缩出来的：黑转白 → LANCZOS 缩到 16×16 → alpha 乘 2.0 提锐化。结果实机看着**发虚**（抗锯齿被摊成一圈半透明灰）、**白块还撑满 16 px**，比 Xaero 最宽的图标还宽三分之一。alpha 锐化只是把灰描深，救不回来；最近邻更糟（X 的对角线中段断成两截）。**结论：别缩，按上面的规格画**。
